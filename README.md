# Курсовой проект — вариант 7
Проект предназначен для учебного моделирования системы мониторинга платёжного терминала с использованием Arduino, датчиков, SQLite и Node-RED.
Состав проекта
- `src/variant_7.ino` — программа для Arduino.
- `src/node_red_function.js` — функция обработки данных в Node-RED.
- `db/schema.sql` — SQL-схема базы данных.
- `db/queries.sql` — контрольные SQL-запросы.
- `db/variant.db` — файл базы данных SQLite.
- `data/log.txt` — демонстрационный журнал событий.
## Создание базы данных
Из корневой папки проекта выполните:
```bat
sqlite3 db/variant.db < db/schema.sql
```
Чтобы проверить таблицы, запустите:
```bat
sqlite3 db/variant.db
```
В консоли SQLite введите:
```sql
.tables
.quit
```
## Проверка SQL-запросов
```bat
sqlite3 -header -column db/variant.db < db/queries.sql
```
Запросы должны соответствовать таблицам, определённым в `db/schema.sql`.
## Важные замечания
Журнал `data/log.txt` является демонстрационным примером, а не доказательством реального испытания. 
Перед сдачей необходимо проверить работу программы, SQL-запросов и потока Node-RED, а также приложить собственные скриншоты моделирования в Wokwi и схемы в EasyEDA.
Пересчёт температуры NTC требует калибровки для конкретного термистора и схемы подключения.
