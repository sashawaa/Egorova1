# Курсовой проект — вариант 7

Сценарий: мониторинг платёжного терминала.

- `src/variant_7.ino` — скетч Arduino Uno.
- `src/node_red_function.js` — функция разбора журнала для Node-RED.
- `db/schema.sql` — схема SQLite.
- `db/queries.sql` — контрольные запросы.
- `data/log.txt` — демонстрационный журнал для проверки парсера.

## Важно
Температура NTC в скетче пересчитывается линейно как учебное допущение. Для реального термистора необходима калибровка. Лог `data/log.txt` — тестовый пример, а не запись реального запуска. Схему EasyEDA и модель Wokwi необходимо собрать по таблице подключений из пояснительной записки и приложить собственные скриншоты.
